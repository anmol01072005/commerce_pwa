## 📌 Overview

**commerce_pwa** is a Progressive Web App (PWA) built for e-commerce use cases. It leverages service workers, offline caching, and PWA installability to deliver a native app-like shopping experience directly in the browser — no app store required.

---

## ✨ Key Features

- 📦 **Installable** — Add to home screen on Android and desktop
- 📶 **Offline Support** — Service worker caches critical assets for offline browsing
- ⚡ **Fast Load Times** — Pre-cached assets for instant page loads
- 🛒 **E-Commerce UI** — Product browsing, cart, and checkout flows

---

## 🚀 Getting Started

```bash
git clone https://github.com/PG1611Bcode/commerce_pwa.git
cd commerce_pwa
npm install
npm run dev
```
